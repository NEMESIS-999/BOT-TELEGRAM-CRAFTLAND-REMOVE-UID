## 🇬🇧 English

### Description

A small open-source Telegram bot to remove or reinsert a UID pattern inside `.bytes` files. Intended for learning, modification, and reuse.

### Features

* Remove UID pattern from `.bytes` files.
* Reinsert a symbolic UID.
* Supports files up to 25MB.
* Released under the MIT License. Source attribution required when redistributing.

### Requirements

* Python 3.9+
* `python-telegram-bot==20.0` (or compatible)

### Install

```bash
python -m venv venv
source venv/bin/activate    # on Windows: venv\Scripts\activate
pip install python-telegram-bot==20.0
```

### Configuration

1. Create a bot with BotFather and get the token.
2. Edit `uid_pattern_bot.py` and set:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```

3. Project files:

* `uid_pattern_bot.py` (bot code)
* `LICENSE` (MIT license)
* `README.md` (this file)

### Run

```bash
python3 uid_pattern_bot.py
```

Open the bot on Telegram. Use `/start` for usage and `/about` for author info.
